# Webflow

This skill orchestrates a set of focused Webflow guides. Pick the sub-skill matching the task:

## Route guide

- **Auditing a site** (structure, pages, CMS health, SEO, migration planning) → open `site-audit/SKILL.md`
- **Building/scaffolding Components** — creating and managing Webflow Components: open `component-scaffold/SKILL.md`
- **CMS** — setting up Collections and Collection fields: open `cms-collection-setup/SKILL.md`; CMS best practices and interactions: open `cms-best-practices/SKILL.md`
- **Design handoff** — turning Figma files into built Webflow pages: open `figma-to-webflow/SKILL.md`
- **Local development** — extending a site or codebase outside the Designer: open `local-dev-setup/SKILL.md`
- **Custom code** — managing site-wide attribute-based custom code: open `custom-code-management/SKILL.md`
- **Pre-deploy validation** — checking bundle size, dependencies, props, SSR, and styling before deploying: open `pre-deploy-check/SKILL.md`
- **Deployment** — deploying Webflow Code Components to the CMS/Dashboard: open `deploy-guide/SKILL.md`
- **Troubleshooting deploys** — diagnosing and fixing failed `webflow library share` deployments: open `troubleshoot-deploy/SKILL.md`

## How to use
1. Identify the Webflow task type from the list above.
2. Open the matching sub-skill `SKILL.md` and follow its step-by-step guidance; consult that sub-skill's `references/` when needed.
3. For cross-cutting concerns, keep the guidance in the relevant sub-skill.
